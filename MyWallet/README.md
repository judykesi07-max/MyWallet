# MyWallet 💰

MyWallet is a personal finance management application designed to help students and small businesses track their income, expenses, savings, and spending habits.

The goal of MyWallet is to make financial management simple by providing users with insights into their money usage and helping them make better financial decisions.

## Features 🚀

- User registration and login
- Deposit and withdrawal tracking
- Wallet balance management
- Transaction history
- Expense categories
- Spending analysis
- Savings goals
- Dashboard with financial summaries
- Reports and financial insights

## Technologies Used 🛠️

- Visual Basic .NET
- Windows Forms
- SQL Server
- Microsoft Visual Studio
- Git & GitHub

## Project Purpose 🎯

MyWallet was created to help students and small businesses manage their finances by tracking cash flow, monitoring expenses, and encouraging better saving habits.
